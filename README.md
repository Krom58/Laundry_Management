# ระบบจัดการร้านซักรีด (Laundry Management System)

**Laundry Management System** คือโปรแกรมสำหรับช่วย **บริหารจัดการงานซักรีด** (Laundry Operations) เช่น การรับออเดอร์ลูกค้า การติดตามสถานะผ้า การคำนวณราคา และการจัดเก็บข้อมูลลูกค้าในฐานข้อมูล  

ระบบถูกออกแบบมาเพื่อช่วยลดความซับซ้อนในการทำงานของร้านซักรีด ทำให้สามารถจัดการข้อมูลได้อย่างเป็นระบบ ลดความผิดพลาด และเพิ่มความรวดเร็วในการให้บริการลูกค้า

---

## ความเป็นมา (Background)

ในธุรกิจร้านซักรีด การจัดการข้อมูลลูกค้า รายการผ้า ราคา และสถานะการทำงาน เช่น  

- รับผ้า  
- ส่งคืนลูกค้า  

มักถูกบันทึกด้วยวิธีพื้นฐาน เช่น การเขียนลงกระดาษ หรือใช้ไฟล์ Excel ซึ่งอาจทำให้เกิดปัญหา เช่น  

- ข้อมูลสูญหาย  
- ค้นหาข้อมูลยาก  
- คำนวณราคาผิดพลาด  
- ไม่สามารถตรวจสอบสถานะงานได้แบบรวดเร็ว  

ดังนั้น **Laundry Management System** จึงถูกพัฒนาขึ้นเพื่อช่วยให้ร้านซักรีดสามารถบริหารจัดการงานทั้งหมดในระบบเดียว โดยข้อมูลทั้งหมดจะถูกเก็บไว้ในฐานข้อมูลอย่างเป็นระเบียบ ทำให้สามารถค้นหา แก้ไข และสรุปรายงานได้ง่ายขึ้น  

### วัตถุประสงค์หลักของระบบ

1. ช่วยจัดการข้อมูลลูกค้าและรายการซักรีดอย่างเป็นระบบ  
2. ลดความผิดพลาดในการคำนวณราคาและบันทึกข้อมูล  
3. สามารถติดตามสถานะงานซักรีดได้อย่างชัดเจน  
4. เพิ่มความรวดเร็วในการให้บริการลูกค้า  

---

## ภาพรวมระบบ (Overview)

ระบบสามารถช่วยจัดการขั้นตอนการทำงานของร้านซักรีดได้ เช่น

- บันทึกข้อมูลลูกค้า  
- เพิ่มรายการผ้าที่ลูกค้านำมาซัก  
- คำนวณราคาอัตโนมัติ  
- ติดตามสถานะงาน เช่น กำลังดำเนินการ / เสร็จแล้ว    
- ค้นหาข้อมูลรายการย้อนหลัง  
- จัดเก็บข้อมูลในฐานข้อมูล (Database)

## คุณสมบัติหลัก (Key Features)

### Customer Management
- เพิ่ม / แก้ไข / ลบ ข้อมูลลูกค้า
- ค้นหาประวัติลูกค้าได้

### Order Management
- บันทึกรายการผ้าที่นำมาซัก
- ระบุประเภทบริการ เช่น ซักน้ำ, ซักแห้ง
- คำนวณราคาตามรายการ

### Database Integration
- จัดเก็บข้อมูลในฐานข้อมูล
- สามารถเรียกดูข้อมูลย้อนหลังได้

### User Interface
- ใช้งานง่าย
- เหมาะสำหรับร้านซักรีดขนาดเล็ก – กลาง
